# Лабораторная работа №2: Геометрические фигуры на Python

## Описание
Программа для работы с геометрическими фигурами с использованием объектно-ориентированного программирования.

## Основные возможности
- Создание геометрических фигур (прямоугольник, круг, квадрат)
- Задание цвета для каждой фигуры
- Вычисление площади фигур
- Вывод подробной информации о фигурах
