# Лабораторная работа №1

**Решение биквадратного уравнения**

Программа для решения биквадратного уравнения, разработанная в виде консольного приложения на языке Python.

**Функциональность**
- Ввод коэффициентов A, B, C с клавиатуры или через параметры командной строки
- Вычисление дискриминанта и действительных корней уравнения
- Валидация вводимых коэффициентов
- Обработка некорректных данных с повторным запросом

**Особенности реализации**
- Поддержка ввода коэффициентов через параметры командной строки
- Проверка корректности введенных данных (преобразование в действительное число)
- Вычисление только действительных корней уравнения
- Две версии программы: процедурная и объектно-ориентированная парадигмы
